# Groupe Axolu CPA — Coming Soon

Page en français, responsive, en HTML/CSS/JavaScript sans dépendances de compilation.

## Aperçu local

`npm run dev` puis ouvrir http://localhost:4173.

## Vérification

`npm run check`

## Déploiement

Publier le contenu de `dist/` sur un hébergement statique (GitHub Pages, Netlify, Vercel, Cloudflare Pages ou serveur web). Aucun serveur applicatif ni secret requis.

## Design et animation

Logos Axolu noir et gris fournis par le client. Le monogramme A s'anime pendant 2 secondes ; le rideau remonte ensuite et dévoile la page progressivement. Bouton pour revoir l'animation. Le réglage système de réduction des animations est respecté. Aucun formulaire ni adresse de contact inventée.

Les polices Google Fonts sont facultatives : des polices système prennent le relais hors connexion.
